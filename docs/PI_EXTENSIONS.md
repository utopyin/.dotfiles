# Vendored Pi extensions

Public-safe vendored Pi extension source lives under `home/common/.pi/agent/extensions`.
Runtime state, OAuth tokens, caches, sessions, and generated node_modules remain
ignored. This follows the official Pi extension layout: simple extensions are
single `.ts` files under `~/.pi/agent/extensions/`, and extensions with npm
dependencies keep their own `package.json`, lockfile, and ignored
`node_modules/` directory beside the extension code. Because Stow links files
without folding directories, `dot init` installs beside the tracked source and
links each live extension's `node_modules` back to that install. The root
TypeScript project stays scoped to the dot CLI (`bin/` and `src/`).

## Managed Pi packages

`pi-mcp-adapter` is installed from npm instead of vendored. Its package source is
pinned in `home/common/.pi/agent/settings.json`, and its resolved dependency graph is
tracked in `home/common/.pi/agent/npm/package-lock.json`. MCP server configuration stays
in `home/common/.pi/agent/mcp.json`; OAuth credentials and metadata caches remain
ignored.

## Computer use runtime

Open Computer Use is pinned as `npm:open-computer-use@0.3.2` in both platform Mise
configs. The `computer` MCP entry launches its stdio server lazily and keeps all nine
tools behind the existing MCP proxy. The runtime controls the logged-in desktop and
needs Accessibility and Screen Recording permission on macOS; it does not use E2B or
require API credentials.

## Web tools decision

Use Davis's Firecrawl tools (`search`, `scrape`, and `crawl`) as the primary web toolset. The vendored extension accepts `FIRECRAWL_API_KEY` only from the process environment; manage it with `dot secrets add FIRECRAWL_API_KEY` rather than a tracked or extension-local `.env` file.

The previous Exa-backed `web-tools`, file-backed `todos`, `pi-btw`, `pi-subagents`, and `pi-worktrees` integrations were removed. Davis's integrated subagent implementation now owns `/btw` and general delegation. Its optional Codex backend is validated against Codex CLI `0.144.3`; the Pi backend does not require that external CLI.
